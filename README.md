It's a model that determines the Total Review (Quantity) from 3 different datasets
I used Pandas to merge, clean and the datasets
I used train test split to split the data, Linear regression, Decision Tree Regressor, ElasticNet, Random Forest Regressor and Gradient booster to train the models
I equally used Column Transformer and a Pipeline plus a simple imputer to deal with missing values, transforms columns into computer understandable format, then r2_score to calculate the accuracy of the mode
